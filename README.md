# Github-User-Activity-CLI

This is my Github User Activity CLI.
I found this project idea on https://roadmap.sh/projects/github-user-activity.

First, enter the username you want to look for.
Then, type "help" in the CLI to see all the available commands.

Due to some limits in the API I cannot make it very precise for the "biggest" users but it works with users who have a few events happening weekly.
